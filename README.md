# Spam-Email-Classifier
Spam Email Detection using Machine Learning with Python and TF-IDF.
## Project Description
Spam Email Classifier is a Machine Learning project developed using Python. It detects whether an email message is Spam or Not Spam.

## Objective
To automatically identify unwanted spam messages using Machine Learning techniques.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- TF-IDF
- Naive Bayes

## Features
- Email text preprocessing
- Spam message detection
- Not Spam message detection
- TF-IDF feature extraction
- Machine Learning classification
- Model performance evaluation

## Dataset
Kaggle Spam Email Dataset:
https://www.kaggle.com/datasets/uciml/sms-spam-collection-dataset

## Project Files
- train_model.py - Model training
- main.py - Spam prediction
- requirements.txt - Required libraries
- dataset/spam.csv - Training dataset

## How to Run
1. Install dependencies using pip install -r requirements.txt
2. Train the model using python train_model.py
3. Run the application using python main.py

## Evaluation
Accuracy, Precision, Recall and F1-score.

## Conclusion
This project demonstrates spam detection using Natural Language Processing and Machine Learning.
